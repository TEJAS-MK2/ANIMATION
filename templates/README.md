# ANIMATION Templates

Starter websites built from the same motion principles as the ANIMATION component library.

## Available

### Creative Portfolio

`templates/portfolio/`

A responsive developer/designer portfolio starter with:

- Animated hero
- Project cards with pointer tilt
- About section
- Contact section
- Responsive mobile layout
- Reduced-motion support
- Dependency-light HTML/CSS/JS
