# v1.1 UI primitive recipes

These recipes show how to adapt the new primitives into framework applications. The source demos remain dependency-free; framework code should preserve the same semantics.

## React

```jsx
export function Toast({ message }) {
  return <div role="status" aria-live="polite">{message}</div>;
}
```

## React tabs

Keep the selected tab in state and mirror it to `aria-selected`, `aria-controls`, and `role="tabpanel"`.

## Tailwind

The primitives can be styled with utility classes. Preserve the semantic HTML and add motion utilities only as progressive enhancement.

```html
<button class="rounded-md border px-4 py-2 transition-transform hover:-translate-y-0.5 focus-visible:outline-2">
  Continue
</button>
```

## Accessibility rule

Do not replace native semantics with a visual-only implementation. Prefer `<button>`, `<details>`, `<dialog>`, headings, and live regions where their behavior matches the component.
