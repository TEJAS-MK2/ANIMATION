Magnetic Button

Cursor-reactive movement that gives buttons a tactile pull.

Code

<button class="magnetic">Magnetic button</button>

.magnetic { transition: transform .15s ease; }

const button = document.querySelector('.magnetic');
button.addEventListener('pointermove', e => {
  const r = button.getBoundingClientRect();
  button.style.transform = `translate(${(e.clientX-r.left-r.width/2)*.22}px, ${(e.clientY-r.top-r.height/2)*.22}px)`;
});
