# ANIMATION Templates

Starter websites built from the same motion and UI principles as the ANIMATION component library.

## Available

| Template | Path | Description |
| --- | --- | --- |
| Creative Portfolio | `templates/portfolio/` | Developer, designer, and creator portfolio. |
| Modern SaaS | `templates/saas/` | Product and startup landing page. |
| Developer Docs | `templates/docs/` | Documentation and developer portal starter. |
| Creative Agency | `templates/agency/` | Editorial agency and studio website. |
| Dashboard | `templates/dashboard/` | Product analytics dashboard starter. |
| Startup Landing | `templates/startup/` | Startup launch and early-access landing page. |

All templates are responsive and designed to be customized. Check each template's source for its specific dependencies and interaction behavior.

## Quality expectations

Templates should remain:

- Responsive on mobile and desktop.
- Understandable without a large framework.
- Reasonably performant.
- Accessible to keyboard and touch users where applicable.
- Compatible with `prefers-reduced-motion` when non-essential motion is present.
- Free of tracking or unexpected network requests.
- Properly licensed and credited.
