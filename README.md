# ANIMATION

A lightweight, accessible open-source UI animation library for the web.

## Collections

- **Components** — reusable interaction and motion primitives.
- **Blocks** — 14 copy-paste sections for real websites, including hero, dashboard, newsletter, process steps, timeline, gallery, team, and bento layouts.
- **Templates** — 8 complete static starters: portfolio, SaaS, docs, journal, event, restaurant, studio, and changelog.
- **Integrations** — framework and ecosystem recipes for Core Web, JavaScript frameworks, CSS systems, and backend/full-stack environments.

## Design principles

ANIMATION favors restrained motion, clear hierarchy, responsive layouts, accessibility, and practical copy-paste usage. Pricing and authentication flows are intentionally excluded from the public blocks collection.

## Getting started

Open the component library from `component.html`, browse sections in `blocks/`, or explore complete sites in `templates/`.

See `docs/` for integration and runtime guidance.
