# Component source packages

The ANIMATION component playground supports downloading standalone source packages directly in the browser.

Each package is intended to contain the component's HTML, CSS, JavaScript, and a small README with usage notes. Downloads are generated locally in the browser; no source code is uploaded to a server.

## Package structure

```text
component-name/
├── index.html
├── style.css
├── script.js
└── README.md
```

Packages should remain dependency-free unless a component explicitly requires a third-party library.
