# Framework snippets

This directory contains the framework-ready source registry for the ANIMATION component collection.

Every component has an entry in `component-snippets.js` with:

- HTML
- CSS
- JavaScript
- React
- Tailwind CSS

The snippets are intentionally small and dependency-light. They are reference implementations for the playground and can be adapted for production projects.

## Quality requirements

Framework snippets should remain behaviorally consistent with the live component preview, support responsive layouts, avoid unnecessary dependencies, and document any framework-specific requirements.
