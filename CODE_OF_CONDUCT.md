# Code of Conduct

## Our commitment

ANIMATION is a welcoming, respectful, and constructive open-source project. Everyone participating in issues, pull requests, discussions, reviews, documentation, and other project spaces is expected to help maintain that environment.

## Expected behavior

- Be respectful, professional, and constructive.
- Assume good intent while still addressing harmful behavior clearly.
- Give specific technical feedback rather than personal criticism.
- Respect different experience levels, backgrounds, cultures, and approaches.
- Keep discussions relevant and avoid unnecessary disruption.
- Credit creators when their work, ideas, or references influence a contribution.
- Prefer evidence, reproducible examples, and clear technical reasoning during disagreements.
- Help keep documentation, examples, and community resources accessible to newcomers.

## Unacceptable behavior

The following behavior is not acceptable:

- Harassment, discrimination, threats, stalking, or personal attacks.
- Hate speech or deliberately demeaning language.
- Sexual harassment or unwelcome sexual content.
- Publishing private, confidential, or sensitive information without permission.
- Trolling, sustained disruption, spam, or deliberate abuse of project resources.
- Malicious code, intentionally harmful contributions, or attempts to compromise users.
- Deliberately introducing tracking, credential collection, or unexpected network requests into project contributions.
- Misrepresenting another person's work as your own.

## Project-specific expectations

Because ANIMATION is an animation and UI toolkit, contributors should also avoid intentionally submitting examples that create misleading security claims, inaccessible interactions, unnecessary resource consumption, or unsafe copy-paste guidance.

## Enforcement

Project maintainers may remove comments, reject contributions, request changes, restrict participation, or take other reasonable action when conduct violates this policy. Enforcement decisions should be proportionate to the behavior and focused on maintaining a healthy project environment.

## Reporting

If you experience or observe unacceptable behavior, report it privately to the project maintainers rather than escalating the situation publicly. For security vulnerabilities, follow [`SECURITY.md`](SECURITY.md) instead of posting sensitive details publicly.

## Scope

This code applies to project spaces and interactions conducted on behalf of ANIMATION, including GitHub issues, pull requests, discussions, reviews, documentation, and community channels associated with the project.
